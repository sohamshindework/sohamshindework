# Asset attribution

- **assets/banner.webp** — Soham Shinde's portfolio artwork, included unchanged.
- **Technology logos** in `assets/badges/` and `assets/contact/` are drawn from
  [Simple Icons](https://simpleicons.org) (CC0 1.0). The source glyphs are kept in `tools/icons/`.
  All trademarks belong to their respective owners.
- **Concept glyphs** (Excel, SQL, Financial Modeling, Monte Carlo, OR-Tools, Forecasting, LLM Integration,
  Model Evaluation, Agile / Scrum, Requirements Analysis, Email) and every illustration in
  `assets/projects/` and `assets/sections/` are original artwork generated by `tools/build_assets.py`.
- **Typefaces**: Cinzel, Cormorant Garamond and Inter, all under the SIL Open Font License 1.1.
  Text is converted to vector outlines at build time; no font files are shipped or loaded.

## Rebuilding the artwork

```bash
python3 -m venv .venv
.venv/bin/pip install fonttools uharfbuzz
.venv/bin/python tools/build_assets.py
```

Edit colours, copy or project titles at the top and bottom of `tools/build_assets.py`.
The script never modifies `assets/banner.webp`.
